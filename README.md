# 📚 الوسيلة الذكية — دليل المشروع وهيكلية المحتوى

## 🎯 نظرة عامة

مشروع **الوسيلة الذكية** هو منصة تعليمية رقمية تحتوي على محتوى المنهج الدراسي اليمني.
تم رقمنة جميع الكتب المدرسية والنماذج الوزارية إلى صور عالية الجودة صفحة بصفحة،
مع فهارس ذكية (JSON + TXT + Excel) لتسهيل البحث والتصفح.

## 📐 أنماط تسمية الملفات

### صور صفحات الكتب المدرسية (مجلد `الصور/`)

| النمط | مثال | الاستخدام |
|-------|-------|-----------|
| `ص{رقم} - {عنوان الدرس}.webp/jpg` | `ص012 - ضرب وقسمة الأعداد المركبة.jpg` | صفحات المحتوى العربي |
| `تمهيدي{رقم} - {وصف}.webp` | `تمهيدي01 - غلاف الكتاب.webp` | الصفحات التمهيدية |
| `PDF{رقم} - {وصف}.webp` | `PDF001 - غلاف الكتاب.webp` | بعض الكتب (القرآن) |
| `front{رقم} - {Title}.jpg` | `front001 - Front Cover.jpg` | الكتب الإنجليزية |
| `p{رقم} - {Title}.jpg` | `p001 - Shapes, coverings and materials.jpg` | صفحات الكتب الإنجليزية |

### صور النماذج الوزارية (مجلد `نماذج وزاريه/`)

| النمط | مثال |
|-------|-------|
| `صفحة_{رقم}.jpg` | `صفحة_1.jpg`, `صفحة_2.jpg`, ... `صفحة_124.jpg` |

## 📄 الملفات المساعدة

كل كتاب يحتوي على ملفات فهرسة ذكية:

| الملف | الوصف | الصيغة |
|-------|-------|--------|
| `manifest.json` | خريطة بيانات الصفحات (رقم الصفحة، العنوان، الدرس) | JSON |
| `دليل_الصور_صفحة_بصفحة.txt` | فهرس نصي لجميع الصفحات | نص عادي |
| `دليل_الصور_صفحة_بصفحة.xlsx` | فهرس جدول بيانات | Excel |
| `تقرير_المعالجة.json` | سجل تقني لعملية التحويل | JSON |

## 🗂️ تنظيم المحتوى

### المرحلة الأولى: ثالث ثانوي (8 مواد)

الكتب مرقمنة بصيغة **WEBP** عالية الدقة (2008×2835).
كل مادة تحتوي على:
- **الكتاب المدرسي**: صفحات مرقمنة في مجلد `الصور/`
- **النماذج الوزارية**: لسنوات 1445 و 1446 و 1447 هجرية بصيغة JPG

المواد:
1. الأحياء
2. الإنجليزي
3. التربية الإسلامية (4 كتب: الإيمان، الحديث، السيرة، الفقه)
4. الرياضيات (فرعين وزارياً: التفاضل والتكامل، الجبر والهندسة)
5. الفيزياء
6. القرآن الكريم
7. الكيمياء
8. اللغة العربية (3 كتب: الأدب والنصوص، القراءة، النحو والصرف)

### المرحلة الثانية: الصف التاسع (7 مواد)

الكتب مرقمنة بصيغة **JPG** (1188×1682).
المواد المكونة من جزأين مقسّمة إلى `الجزء_الأول` و `الجزء_الثاني`.

المواد:
1. الاجتماعيات (4 فروع: التربية الوطنية، التاريخ ج1+ج2، الجغرافيا)
2. التربية الإسلامية (جزأين)
3. القرآن الكريم
4. اللغة العربية (جزأين)
5. الإنجليزي
6. الرياضيات (جزأين)
7. العلوم (جزأين)

## ⚙️ سكريبت تحسين الصور

### الملف: `optimize_images.py`

سكريبت Python لتقليل حجم الصور مع الحفاظ على الجودة البصرية.

### الأوامر المتاحة:

```bash
# معاينة بدون تعديل (لرؤية النتائج المتوقعة)
python optimize_images.py --dry-run

# تقرير بالأحجام الحالية فقط
python optimize_images.py --report-only

# تشغيل الضغط (الإعداد الافتراضي — جودة 85%)
python optimize_images.py

# تحديد جودة مخصصة
python optimize_images.py --quality 80    # ضغط أقوى
python optimize_images.py --quality 90    # ضغط أخف

# استعادة النسخ الاحتياطية
python optimize_images.py --restore
```

### مميزات السكريبت:
- ✅ يحتفظ بنفس أسماء الملفات والمسارات
- ✅ ينشئ نسخاً احتياطية تلقائياً
- ✅ يتحقق من سلامة الصور بعد الضغط
- ✅ يتخطى الصور الصغيرة التي لا تحتاج ضغط
- ✅ يستعيد الأصل تلقائياً إذا فشل الضغط
- ✅ يُنتج تقريراً مفصلاً بصيغة JSON
- ✅ معالجة متعددة الخيوط للسرعة

### استراتيجية الضغط:

| النوع | الطريقة |
|-------|---------|
| **JPG** | Progressive JPEG + Optimize Huffman + 4:2:2 Chroma Subsampling |
| **WEBP** | Method 6 (أبطأ وأفضل ضغط) + جودة أعلى بـ 3% من JPG |

## 🚀 دليل الرفع للموقع

### الخطوات:
1. شغّل سكريبت التحسين: `python optimize_images.py`
2. تأكد من النتائج في التقرير: `تقرير_تحسين_الصور.json`
3. ارفع المشروع للمستودع

### ملاحظات مهمة:
- ❗ **لا تحذف** مجلد `_نسخ_احتياطية_الصور/` حتى تتأكد من صحة الصور المضغوطة
- ❗ **لا ترفع** مجلد النسخ الاحتياطية للمستودع (أضفه في `.gitignore`)
- ❗ ملف `تقرير_تحسين_الصور.json` يحتوي على تفاصيل كل صورة
