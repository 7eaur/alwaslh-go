# الأسئلة المنظمة — ثالث ثانوي، 1445هـ

هذا المجلد مخصص لبيانات الأسئلة المستخرجة من صور النماذج الوزارية في المصدر الأساسي.

## قاعدة الدقة

- يتم استخراج نصوص الأسئلة والخيارات فقط، من دون إجابات.
- يحتفظ كل سؤال باسم صفحة السؤال المصدرية.
- أي نص أو رسم غير واضح يُعلَّم `needs_manual_review` ولا تُخمَّن له إجابة.
- ترقيم النموذج يتبع الترتيب الفعلي للصور، مع تجاهل صفحة التصحيح عند بناء بيانات الأسئلة.
