# الأسئلة المنظمة — ثالث ثانوي، 1445هـ

هذا المجلد مخصص لبيانات الأسئلة المستخرجة من صور النماذج الوزارية في المصدر الأساسي.

## قاعدة الدقة

- لا تُسجَّل إجابة إلا من صفحة **نموذج التصحيح الإلكتروني** المرتبطة بالنموذج نفسه.
- يحتفظ كل سؤال باسم صفحة السؤال واسم صفحة التصحيح المصدرية.
- أي نص أو رسم غير واضح يُعلَّم `needs_manual_review` ولا تُخمَّن له إجابة.
- ترقيم النموذج يتبع الترتيب الفعلي للصور: كل نموذج يتكوّن من صفحتين للأسئلة ثم صفحة تصحيح.
